# Henri Simamora & Partners

Situs profil HENRI SIMAMORA & PARTNERS berbahasa Indonesia, dibangun dengan HTML, CSS, dan JavaScript tanpa proses build atau dependensi proyek. Informasi layanan, visi, misi, lokasi, dan kontak mengikuti data yang diberikan.

## Menjalankan secara lokal

Dari folder proyek, jalankan:

```powershell
python -m http.server 8000
```

Buka `http://localhost:8000` di browser.

## Halaman

- `index.html` — Beranda
- `tentang-kami.html` — Tentang firma
- `bidang-praktik.html` — Bidang keahlian
- `tim.html` — Alur konsultasi
- `wawasan.html` dan `artikel.html` — Artikel dan perspektif
- `kontak.html` — Formulir konsultasi
- `kebijakan-privasi.html` — Kebijakan privasi

Formulir konsultasi menyiapkan draf melalui aplikasi email pengguna dan mengarahkannya ke `hspatnerslawfirm@gmail.com`. Pesan hanya terkirim jika pengguna menekan Kirim di aplikasi email; situs ini belum terhubung ke backend atau layanan pengiriman formulir. Nomor telepon/WhatsApp dan profil individual tidak ditampilkan karena belum tersedia. Foto dimuat dari Unsplash dan font dari Google Fonts.
